# 🎧 Neural Notes

> **A Modern Music Streaming Web Application powered by YouTube Data API v3**

Neural Notes is a responsive music streaming web application built using HTML, CSS, and Vanilla JavaScript. It allows users to search, play, and organize music using the YouTube Data API v3 and YouTube IFrame Player API while providing a clean, modern, and user-friendly interface inspired by popular music streaming platforms.

---

## ✨ Features

| Feature | Description |
|---|---|
| 🎵 Search | Find songs, artists, albums, and playlists |
| ▶️ Playback | Audio & Video playback support |
| 🎤 Voice Search | Hands-free search experience |
| ❤️ Favorites | Save and manage favorite songs |
| 📂 Custom Playlists | Create and organize your own playlists |
| 📋 Music Queue | Queue up songs for continuous playback |
| 🕒 History | Recently played tracks |
| 🌙 Theme | Dark / Light mode toggle |
| 🔀 Playback Modes | Shuffle & Repeat support |
| 🔊 Volume Control | Fine-grained audio control |
| 😴 Sleep Timer | Auto-stop playback after a set time |
| 📱 Responsive | Fully responsive design for all devices |
| 💾 Local Storage | Persistent data stored in the browser |
| 🎨 Modern UI | Glassmorphism-inspired interface |
| ⚡ Lightweight | Fast with no dependencies required |

## 🔑 YouTube API Setup

This project requires your own **YouTube Data API v3 Key**.

### Steps

1. Open [Google Cloud Console](https://console.cloud.google.com/)
2. Create or select a project
3. Enable **YouTube Data API v3**
4. Go to **APIs & Services → Credentials**
5. Create an **API Key**
6. Launch the application
7. Paste your API Key when prompted
8. Enjoy streaming music 🎶
